# Aishwarya Kanani — Portfolio

**My personal portfolio** — a modern, responsive single-page site built with pure HTML/CSS/JS, deployed to GitHub Pages.

🌐 **Live:** https://aishwaryakanani.github.io/

---

## ✨ Features

- **Animated role rotator** — typing effect cycling through roles
- **Scroll progress indicator** — gradient bar at top
- **Reveal-on-scroll animations** — sections animate in as you scroll
- **Responsive design** — works on mobile, tablet, and desktop
- **Dark theme** — professional dark UI with cyan accent
- **Project cards** — clickable links to live dashboards and GitHub
- **Skills visualization** — animated progress bars by category
- **Timeline layout** — clean experience history with dot markers
- **Contact section** — location, phone, email, and downloadable CV

## 🧰 Tech

- Pure HTML5 + CSS3 (no framework dependencies)
- Vanilla JavaScript (typing animation, scroll observer)
- Google Fonts — Inter + JetBrains Mono
- Deployed via GitHub Pages (static hosting)

---

## 🚢 Deployment

This site auto-deploys to GitHub Pages on every push to `main`.

1. Push changes: `git push origin main`
2. GitHub Pages builds and serves from root
3. Live at: https://aishwaryakanani.github.io/
